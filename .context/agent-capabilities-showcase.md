## 二、能力模块详解

### 2.1 市场调研

| Skill | 能力描述 | 触发场景 |
|-------|---------|---------|
| **ma-market-analysis** | 系统分析市场规模、品类趋势、品类痛点，输出品牌与营销策略所需的市场输入 | "市场分析"、"市场规模"、"品类趋势"、"行业分析" |
| **ma-competitor-analyzer** | 竞品社媒诊断与竞争情报，分析竞品的社交媒体策略、内容表现、达人合作 | "竞品分析"、"竞争情报"、"差异化策略" |
| **ma-consumer-insight** | 消费者洞察提炼，从 Observation → Insight → Tension → Entry Point 层层递进 | "消费者洞察"、"用户洞察"、"痛点分析" |
| **ma-ta-portrait** | 目标受众（TA）画像构建，包含 demographics、psychographics、行为特征 | "TA画像"、"目标受众"、"用户画像" |

**核心输出**：
- 市场分析报告（市场规模/趋势/痛点）
- 竞品社媒诊断报告
- 消费者洞察文档
- TA 画像卡片

### 2.2 营销策划

| Skill | 能力描述 | 触发场景 |
|-------|---------|---------|
| **ma-marketing** (Flow 复楼) | 总纲 Skill，整合策略生成、KOL匹配、智能建联、创意指导四大能力 | 完整营销 Campaign 规划 |
| **ma-brand-dna** | 品牌 DNA 提取（核心价值/品牌人格/产品定位） | 品牌策略、品牌焕新、新品诊断 |
| **ma-brand-house** | 品牌屋结构化生成（愿景/使命/价值观/品牌金字塔） | 品牌屋搭建、品牌主张制定 |
| **ma-creative-concept** | 创意概念与 Big Idea 生成，含 DDB ROI 评估和 STEPPS 病毒性自检 | Campaign 创意发想、传播主题制定 |
| **ma-creative-roi** | 创意 ROI 评估（DDB ROI + 李奥贝纳 Inherent Drama） | 创意筛选、比稿评估 |
| **ma-platform-role-mapper** | 平台角色定位与策略分配（小红书/抖音/B站/微博/快手） | 多平台策略、平台矩阵 |
| **ma-content-calendar** | 跨平台内容日历规划，排期、月度规划、内容统筹 | 内容排期、月度规划 |
| **ma-paid-media** | 付费媒体投放策略（广告投放、信息流、预算分配） | 投放策略、预算规划 |
| **ma-ugc-campaign** | UGC 互动营销活动设计（用户共创、互动活动、裂变） | UGC 活动、裂变活动 |
| **ma-kol-pyramid** | KOL 金字塔投放策略（头部/腰部/KOC 配比） | KOL 配比、达人预算分配 |
| **ma-tone-manner** | 品牌语气调性定义，统一内容风格 | 品牌调性、内容风格统一 |

**核心输出**：
- 品牌 DNA 报告
- 品牌屋文档
- 创意概念方案（含 Big Idea + DDB ROI 评分）
- 平台矩阵策略
- 内容日历
- 投放策略方案

### 2.3 文案生成

| Skill | 能力描述 | 触发场景 |
|-------|---------|---------|
| **ma-script-studio** | 脚本工坊，生成故事脚本、分镜脚本、视频拍摄指导，内建 Cialdini 六原则 + STEPPS 框架 | "脚本"、"分镜"、"视频指导"、"拍摄脚本" |
| **ma-creative-pilot** (工具) | 创意内容指导，生成个性化创意 Brief、平台-specific 脚本建议、合规性预审 | KOL 内容创作指导 |

- 故事脚本（完整故事弧线 + 场景分解 + 对话设计）

## 四、核心亮点

### 4.1 全链路覆盖
从市场调研 → 营销策划 → 文案生成 → 达人建联 → 内容审核 → 数据追踪 → 复盘优化，形成完整闭环。

### 4.2 自动化能力
- **KOL 采集自动化**：蒲公英平台批量采集 + 8 阶段筛选流水线
- **建联自动化**：微信自动回复守护进程，7×24 小时自动跟进
- **审核自动化**：飞书群机器人自动审稿，三态判定
- **数据追踪自动化**：发布数据自动追踪 + 异常预警

### 4.3 专业框架
- **DDB ROI**：Relevance / Originality / Impact 三维度创意评估
- **STEPPS**：Social Currency / Triggers / Emotion / Public / Practical Value / Stories 病毒性自检
- **Cialdini 六原则**：互惠 / 承诺一致 / 社会认同 / 权威 / 喜好 / 稀缺
- **奥格威双框架**：品牌形象 + 广告调查

### 4.4 数据驱动
- 4 维度确定性打分（CPE/点赞率/赞评比/爆文率）
- 互暖排查（三层评分 + 红线条）
- 业务健康度评分卡
- 三分决策（保持放大/停止/新开始）

## 五、应用场景

### 场景 1：新品上市全案
```
市场调研（ma-market-analysis）→ 品牌DNA（ma-brand-dna）→ 创意概念（ma-creative-concept）
→ 平台策略（ma-platform-role-mapper）→ KOL筛选（ma-kol-scraper）→ 建联（ma-pgy-invite）
→ 内容审核（ma-draft-review）→ 数据追踪（ma-publish-data-track）→ 复盘（ma-campaign-review）
```

### 场景 2：KOL 投放快速测试
```
KOL采集（ma-kol-scraper）→ 智能匹配（match-ai）→ 邀约（connect-bot）
→ 内容指导（creative-pilot）→ 发布追踪（ma-publish-data-track）→ 阶段复盘（ma-phase-reviewer）
```

### 场景 3：业务诊断与增长
```
业务诊断（ma-business-strategy）→ 市场分析（ma-market-analysis）→ 竞品分析（ma-competitor-analyzer）
→ 消费者洞察（ma-consumer-insight）→ 增长策略（ma-business-strategy）
```
