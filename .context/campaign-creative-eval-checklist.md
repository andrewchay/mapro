# MA-Proma Campaign 创意评估 Checklist

> 基于大卫·奥格威「品牌形象 + 广告调查」双框架设计的 KOL Campaign 创意评估体系
> 版本: v1.0 | 适配 MA-Proma Content Audit Service

---

## 框架定位

奥格威的两大核心洞见，在现代 KOL Campaign 中依然成立：

1. **品牌形象是长期投资，而非一次性活动** —— 每一则 KOL 内容都应被视为品牌资产的累积，而非孤立的交易
2. **调查是广告创作的基础，而非创意的敌人** —— 用数据验证假设，用反馈迭代创意

本 Checklist 将奥格威的 7 条核心原则映射为 **3 大评估维度 × 7 项评估模块 × 21 条具体指标**，与 MA-Proma 现有 `ContentAuditService` 的三维评分体系（合规性 / 品牌契合度 / 内容质量）对齐，并新增 **「品牌形象一致性」** 和 **「数据可验证性」** 两个奥格威专属维度。

---

## 一、核心原则映射

| 奥格威原话 | 现代 KOL Campaign 诠释 | 评估维度 |
|:---|:---|:---|
| "广告的目的是销售，否则就不是广告" | KOL 内容必须有明确的转化目标（种草/引流/转化），而非纯曝光 | 策略对齐 |
| "承诺，大大的承诺，是广告的灵魂" | KOL 内容必须包含一个清晰、可感知、可验证的产品承诺 | 品牌契合度 |
| "品牌形象是一项长期投资" | 所有 KOL 内容的调性、视觉、语言风格必须与品牌人格一致 | 品牌形象一致性 |
| "好广告是不引公众注意它自己就把产品推销掉的作品" | KOL 内容不应让观众感叹"这个博主好会拍"，而应是"这个产品我想试试" | 内容质量 |
| "消费者不是低能儿，她是你的妻子" | 尊重受众智商，提供真实事实和数据，拒绝空洞形容词 | 内容质量 |
| "调查是广告创作的基础" | 每条 KOL 创意必须有前置数据支撑（受众洞察/竞品分析/历史数据） | 数据可验证性 |
| "委员会可以对广告提意见，但决不能让他们创作广告" | KOL 的创意自主权应受尊重，但品牌方需明确边界（Brief 的约束与释放） | 策略对齐 |

## 二、五维评估体系

### 维度总览

```
┌─────────────────────────────────────────────────────────────┐

├─────────────┬─────────────┬─────────────┬─────────┬─────────┤
│  合规性     │ 品牌契合度   │ 内容质量     │ 品牌形象 │ 数据验证 │
│  (20%)     │   (25%)     │   (25%)     │  (20%)  │  (10%)  │
├─────────────┼─────────────┼─────────────┼─────────┼─────────┤
│ 法律合规    │ 承诺清晰度   │ 创意原创性   │ 调性一致 │ 前置洞察 │
│ 平台规范    │ 卖点传达     │ 信息密度     │ 视觉一致 │ A/B 测试 │
│ 风险词检测  │ 产品露出     │ 互动设计     │ 人格一致 │ 历史对标 │
│             │ CTA 明确性   │ 叙事结构     │         │         │
└─────────────┴─────────────┴─────────────┴─────────┴─────────┘
```

### 评分标准

| 等级 | 分数 | 判定 | 行动 |
|:---|:---|:---|:---|
| 🟢 优秀 | 90-100 | 可直接发布 | 记录最佳实践，作为后续 Brief 参考案例 |
| 🟡 良好 | 70-89 | 需微调后发布 | 明确修改点，24h 内复核 |
| 🟠 一般 | 50-69 | 需修改后重审 | 退回达人，附具体修改建议 |
| 🔴 不合格 | 0-49 | 大幅修改或拒绝 | 终止合作或更换达人 |

## 三、21 项详细评估指标

### 维度 1：合规性（Compliance）— 20%

> 对应奥格威原则：*"不要推出一个你不愿意你的家人看到的广告"*

| # | 指标 | 权重 | 检查项 | 通过标准 |
|:---|:---|:---|:---|:---|
| 1.1 | **广告法合规** | 8% | □ 未使用绝对化用语（最、第一、国家级、纯天然、无副作用等）<br>□ 未涉及医疗/药品/保健品等特殊领域的违规宣称<br>□ 金融类产品未承诺保本/保收益<br>□ 食品/化妆品未宣称治疗功效 | 零违规用词 |
| 1.2 | **平台规范** | 7% | □ 符合投放平台的社区规范（小红书/抖音/B站/微博等）<br>□ 未触碰平台限流敏感词或画面<br>□ 商业合作标识清晰（# sponsored / 合作 / 广告） | 平台审核通过率 > 95% |
| 1.3 | **品牌安全** | 5% | □ 内容场景不涉及政治、宗教、种族等敏感话题<br>□ 达人近期无负面舆情<br>□ 未与竞品同框或提及 | 品牌安全评分 ≥ 90 |

**MA-Proma 现有能力对接**：`ContentAuditService` 的 `complianceScore` 已覆盖 1.1-1.2，需扩展 1.3 的品牌安全模块。

---

### 维度 2：品牌契合度（Brand Alignment）— 25%

> 对应奥格威原则：*"承诺，大大的承诺，是广告的灵魂"* + *"每一则广告都是对品牌形象的贡献"*

| # | 指标 | 权重 | 检查项 | 通过标准 |
|:---|:---|:---|:---|:---|
| 2.1 | **核心承诺清晰度** | 10% | □ 内容包含一个明确的产品承诺（非功能罗列，而是用户利益点）<br>□ 承诺与 Brief 中定义的「Key Message」一致<br>□ 承诺可被感知和验证（非空洞形容词） | 受众能在 3 秒内复述核心承诺 |
| 2.2 | **卖点传达完整度** | 8% | □ 包含 Brief 中要求的 ≥ 2 个核心卖点<br>□ 卖点以「场景化」方式呈现，非罗列参数<br>□ 卖点与目标受众痛点精准匹配 | 卖点覆盖率 100%，场景化率 ≥ 80% |
| 2.3 | **产品/品牌露出** | 4% | □ 品牌名出现 ≥ 2 次（自然语境下）<br>□ 产品视觉露出 ≥ 3 秒（视频）或 ≥ 1 张清晰图（图文）<br>□ 未出现「品牌名误写/Logo 变形/产品包装损坏」 | 品牌露出自然，无硬广感 |
| 2.4 | **CTA 明确性** | 3% | □ 包含清晰的行动号召（点击链接/搜索关键词/评论互动等）<br>□ CTA 与 Campaign 目标一致（种草 vs 转化 vs 私域） | CTA 明确且可追踪 |

**MA-Proma 现有能力对接**：`ContentAuditService` 的 `brandAlignmentScore` 已覆盖 2.3-2.4，需扩展 2.1-2.2 的承诺清晰度评估（可引入 LLM 语义分析）。

---

### 维度 3：内容质量（Content Quality）— 25%

> 对应奥格威原则：*"好广告是不引公众注意它自己就把产品推销掉的作品"* + *"消费者不是低能儿"*

| # | 指标 | 权重 | 检查项 | 通过标准 |
|:---|:---|:---|:---|:---|
| 3.1 | **创意原创性** | 8% | □ 非模板化/流水线内容（非「大家好我是 XX，今天测评 XX」式开场）<br>□ 有个人风格或独特切入角度<br>□ 未直接搬运竞品或过往内容 | 原创度评分 ≥ 80（可通过文本相似度检测） |
| 3.2 | **信息密度与事实支撑** | 8% | □ 提供具体事实/数据/使用场景，非纯主观感受（「用了 7 天，出油量减少 43%」>「很好用」）<br>□ 信息密度适中：不空洞（字数/时长达标），不冗长（无废话）<br>□ 尊重受众智商：不假设受众无知，也不过度专业 | 事实陈述占比 ≥ 30%，形容词占比 ≤ 20% |
| 3.3 | **互动设计** | 5% | □ 包含明确的互动引导（提问/投票/抽奖/评论区话题等）<br>□ 互动设计与内容主题相关，非生硬插入 | 预期互动率 ≥ 行业均值 1.2x |
| 3.4 | **叙事结构** | 4% | □ 有清晰的开头-冲突-解决方案-结尾结构<br>□ 开头 3 秒/首图能抓住注意力<br>□ 结尾有记忆点（金句/反转/悬念） | 完播率/阅读完成率 ≥ 行业均值 |

**MA-Proma 现有能力对接**：`ContentAuditService` 的 `qualityScore` 已覆盖 3.1-3.4 的基础版本，建议引入「事实陈述 vs 形容词」的 NLP 分析增强 3.2。

### 维度 4：品牌形象一致性（Brand Image Consistency）— 20%

> 对应奥格威原则：*"品牌形象是一项长期投资，而非一次性活动"*

这是奥格威框架在 MA-Proma 中的**新增维度**，现有 `ContentAuditService` 未覆盖。

| # | 指标 | 权重 | 检查项 | 通过标准 |
|:---|:---|:---|:---|:---|
| 4.1 | **调性一致性** | 8% | □ 语言风格与品牌人格一致（如：高端品牌 = 克制/优雅/专业；年轻化品牌 = 活泼/网感/共情）<br>□ 情绪基调与品牌定位匹配（如：护肤品牌 ≠ 焦虑贩卖）<br>□ 达人人设与品牌调性不冲突（如：高端护肤 ≠ 搞笑剧情博主） | 调性匹配度评分 ≥ 85 |
| 4.2 | **视觉一致性** | 6% | □ 画面色调/滤镜风格与品牌 VI 不冲突<br>□ 产品展示角度/场景与品牌视觉规范一致<br>□ 未出现与品牌形象冲突的背景元素（如：奢侈品在杂乱环境） | 视觉合规率 100% |
| 4.3 | **人格一致性** | 6% | □ 达人表达方式与品牌「角色设定」一致（如：品牌作为「专家朋友」vs「潮流引领者」）<br>□ 内容传递的价值观与品牌使命不冲突<br>□ 长期合作达人的内容风格呈现一致性（非每次判若两人） | 品牌人格识别度 ≥ 80 |

**实施建议**：建立品牌「人格卡片」和「视觉规范库」，作为 `ContentAuditService` 的输入参数，供 LLM 审核时参考。

### 维度 5：数据可验证性（Data Verifiability）— 10%

> 对应奥格威原则：*"调查是广告创作的基础，而非创意的敌人"*

这是奥格威框架在 MA-Proma 中的**新增维度**，强调「前置验证」而非「事后审核」。

| # | 指标 | 权重 | 检查项 | 通过标准 |
|:---|:---|:---|:---|:---|
| 5.1 | **前置洞察支撑** | 4% | □ 创意概念有 Brief 中引用的数据/洞察支撑（非拍脑袋）<br>□ 目标受众画像与 KOL 粉丝画像匹配度 ≥ 70%<br>□ 核心卖点有消费者调研或竞品分析支撑 | 每条创意可追溯到 ≥ 1 条数据源 |
| 5.2 | **A/B 测试就绪** | 3% | □ 创意可拆解为可测试变量（标题/封面/开头/CTA 等）<br>□ 已设定明确的测试指标（CTR/互动率/转化率）<br>□ 测试方案已写入 Brief | 可测试元素 ≥ 3 个 |
| 5.3 | **历史对标基准** | 3% | □ 已调取同品类/同平台/同量级 KOL 的历史 Benchmark 数据<br>□ 预期 KPI 基于历史数据设定，非主观臆断<br>□ 已明确「成功/失败」的量化判定标准 | 有历史 Benchmark 参考 |

**实施建议**：在 MA-Proma 的 Campaign 创建阶段（Step A1-A2）即引入「数据验证」环节，将数据源、Benchmark、测试方案作为 Brief 的必填字段，而非仅在内容产出后审核。

## 四、评分计算与判定流程

### 总分计算

```
总分 = 合规性 × 0.20 + 品牌契合度 × 0.25 + 内容质量 × 0.25 + 品牌形象一致性 × 0.20 + 数据可验证性 × 0.10

其中每个维度得分 = Σ(指标得分 × 指标权重)
```

### 审核流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  达人提交    │ → │  MA-Proma   │ → │  人工复核   │ → │  发布/退回  │
│   内容      │    │  AI 初筛    │    │  关键项     │    │  迭代       │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
       │                  │                  │
       │            ┌─────┴─────┐            │
       │            ▼           ▼            │
       │      规则打分       LLM 审核        │
       │      (无 API Key)  (有 API Key)     │
       │            │           │            │
       └────────────┴───────────┴────────────┘
                    │
                    ▼
              五维评分输出
              + 修改建议
```

### 关键项判定（一票否决）

以下任何一项触发，直接判定为 🔴 不合格：

- [ ] 出现广告法明令禁止的用语（最、第一、国家级等）
- [ ] 涉及虚假宣传（如：普通食品宣称治疗功效）
- [ ] 品牌名/Logo 错误、变形或负面呈现
- [ ] 达人与品牌调性严重冲突（如：高端护肤 × 搞笑剧情博主）
- [ ] 内容涉及政治/宗教/种族等敏感话题
- [ ] 抄袭或高度相似于竞品/过往内容（原创度 < 50%）

## 五、Brief 设计指南（前置输入）

> 奥格威：*"花极大苦功准备"* —— 80% 的审核质量取决于 Brief 的质量。

为确保 Checklist 能有效执行，Brief 必须包含以下字段：

### 必填字段

| 字段 | 说明 | 示例 |
|:---|:---|:---|
| **Campaign 目标** | 明确是「品牌认知」/「种草」/「转化」/「私域」 | 种草：提升天猫搜索量 30% |
| **Key Message** | 唯一核心承诺（非卖点罗列） | "7天减少出油43%，油皮本命水乳" |
| **核心卖点（≤3个）** | 带事实/数据支撑的卖点 | ① 7天控油 -43% ② 0 酒精 0 致痘 ③ 三甲医院皮肤科推荐 |
| **目标受众画像** | 年龄/性别/城市/兴趣/痛点 | 18-25岁，一二线城市，油皮/混油皮，关注成分党 |
| **品牌人格卡片** | 语言风格/情绪基调/角色定位 | 专家朋友：专业但不说教，温暖但不煽情 |
| **视觉规范** | 色调/场景/产品展示要求 | 清新自然光，实验室/浴室场景，产品 45° 展示 |
| **CTA 指令** | 明确的行动号召 | "评论区告诉我你的肤质，抽3位送正装" |
| **数据支撑** | 核心承诺的数据来源 | 第三方检测机构报告 #2024-XX-XX |
| **历史 Benchmark** | 同品类/同平台参考数据 | 同量级 KOL 平均 CPE 5.2，互动率 4.8% |
| **KOL 调性要求** | 达人类型/人设/禁区 | 成分党/测评类优先，拒绝纯剧情/擦边博主 |

### 禁止清单（Don'ts）

| 类型 | 禁止项 | 原因 |
|:---|:---|:---|
| 语言 | 不得使用「最」「第一」「绝对」「100%」等绝对化用语 | 广告法合规 |
| 语言 | 不得贬低竞品（明示或暗示） | 商业诋毁风险 |
| 视觉 | 不得使用未授权的明星/网红形象 | 肖像权风险 |
| 视觉 | 不得出现产品包装破损/过期/非卖品版本 | 品牌形象损害 |
| 内容 | 不得制造容貌/身材/年龄焦虑 | 平台规范 + 品牌安全 |
| 内容 | 不得暗示「不用这个产品就会变丑/失败」 | 负面情绪关联 |

## 六、奥格威式「神灯」方法论在 KOL Campaign 中的应用

奥格威的「神灯」（Magic Lantern）方法论建立在 5 个信息来源之上。我们将其映射为现代 KOL Campaign 的数据来源：

| 奥格威的原始来源 | 现代 KOL Campaign 对应 | MA-Proma 数据接入点 |
|:---|:---|:---|
| 邮购公司广告经验 | KOL 历史带货数据 / CPS 转化追踪 | `kol-data-service` 历史 ROI 数据 |
| 百货商店成功/失败案例 | 同品类 KOL Campaign 的 Benchmark | 竞品 Campaign 数据抓取 |
| 盖洛普/斯塔奇调查 | 受众画像匹配度 / 内容互动率预测 | 平台公开数据 + KOL 粉丝分析 |
| 电视广告调查数据 | 短视频完播率 / 图文阅读完成率 | 内容发布后数据回流（`content-tracker`） |
| 学习先辈和竞争者 | 竞品 KOL 内容策略分析 | 竞品内容库 + AI 分析 |

**落地建议**：在 MA-Proma 的 Campaign 创建阶段，自动调取以上 5 类数据，生成「数据洞察摘要」作为 Brief 的附件，确保每一条创意都有数据支撑。

## 七、迭代优化机制

> 奥格威：*"我从在普林斯顿随盖洛普博士做调查工作开始我的职业生涯。"*

Campaign 不是一锤子买卖，而是持续迭代的过程：

```
Phase 1: Brief 设计（数据驱动）
    ↓
Phase 2: KOL 内容创作（创意自由 + Brief 约束）
    ↓
Phase 3: AI 初筛（五维评分 + 修改建议）
    ↓
Phase 4: 人工复核（关键项一票否决 + 品牌调性终审）
    ↓
Phase 5: 发布（A/B 测试就绪）
    ↓
Phase 6: 数据回流（互动率/转化率/CPE/CPM）
    ↓
Phase 7: 复盘归档（最佳实践入库，失败案例归因）
    ↓
[返回 Phase 1，迭代下一轮 Campaign]
```

**复盘模板**：

| 复盘项 | 数据 | 归因 | 改进动作 |
|:---|:---|:---|:---|
| 互动率低于预期 | 3.2% vs Benchmark 4.8% | 开头 3 秒吸引力不足 | 下期 Brief 强化「黄金 3 秒」要求 |
| CPE 过高 | ¥8.5 vs 目标 ¥5.0 | KOL 粉丝画像与目标受众偏差 | 优化 `kol-data-service` 匹配算法 |
| 品牌搜索量提升 | +45% | Key Message 清晰 + CTA 明确 | 将本案例纳入「最佳实践库」 |

## 附录：与 MA-Proma 现有系统的对接建议

### 1. ContentAuditService 扩展

在现有三维评分基础上，增加「品牌形象一致性」和「数据可验证性」两个维度：

```typescript
export interface AuditScores {
  auditStatus: ContentAudit['auditStatus']
  complianceScore: number        // 合规性 (20%)
  brandAlignmentScore: number    // 品牌契合度 (25%)
  qualityScore: number           // 内容质量 (25%)
  brandImageScore: number        // 品牌形象一致性 (20%) ← 新增
  dataVerifiabilityScore: number // 数据可验证性 (10%) ← 新增
  overallScore: number
  auditReport: string
  auditor: string
}
```

### 2. Prompt 模板扩展

在 `buildSystemPrompt()` 中增加品牌形象和数据验证的审核维度：

```
**新增审核维度：**
4. **品牌形象一致性**：调性一致性、视觉合规性、品牌人格匹配
5. **数据可验证性**：前置洞察支撑、A/B 测试就绪度、历史 Benchmark 对标
```

### 3. Brief 模板标准化

将「五维评估体系」的输入要求（品牌人格卡片、视觉规范、数据支撑等）固化为 Campaign 创建的必填表单字段。

### 4. 最佳实践库

建立 `campaign-best-practices` 数据表，存储每次 Campaign 的评分结果、复盘归因和改进动作，供后续 Campaign 的 Brief 设计阶段参考。
