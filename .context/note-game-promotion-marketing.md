# 2026-09-29 游戏宣发方法论向营销迁移的判断

基于用户提供的方法论文本进行概念评议，非外部实证结论；以下建议尚未得到用户确认，不代表已决定修改营销 Skills。

## 核心结论
适合作为有明确转化窗口的 Campaign 策划与评估框架，不宜直接升级为营销总纲。原文隐含：产品既定、用户对品类已有认识、上线时间明确、稀缺资源竞争、行为可在端内观测。营销还包含需求研究、产品与价值设计、定价、渠道供给、长期品牌建设。

## 可迁移
- 从素材/渠道清单转为受众决策变化：当前认知、希望改变的判断、阻碍、证据、下一步行动。
- 内容按功能而非格式分，触点按阶段×人群×职能规划。
- 按动机、情境、障碍分人群，并保留人口统计和媒介可达性维度。
- 核心主张一致，依据受众调整证据；内容承诺与产品、购买链路对齐。
- 先定义目标人群、指标、窗口和比较基准，区分交付、相关、增量。

## 需要修正的绝对表述
- 宣发只作用于预期：也可能影响记忆可得性、理解成本、风险感知和即时行动；营销更可改变购买摩擦和价值供给。
- 节奏第一、集中兑现：适合发布活动；常态营销需覆盖分散出现的需求时刻。
- 官方信任最高、渠道角色固定：权威信息源不等于独立证据源；按具体内容、关系和决策阶段配置职能。
- 各层是必要条件：是规划诊断链，不是每个消费者必须顺序经过的因果路径；增量是评估维度而非心理阶段。
- 无随机化只能相关：合格的准实验在识别假设成立时可支持因果推断；归因分账不等于增量识别。
- 不能归因不算效果：应改为不能识别增量，不能宣称已证明因果；证据不足不等于无效。
- 双窗口足够：增加活动后窗口，识别提前购买、渠道迁移、SKU蚕食、折扣成本及留存变化；区分收入与贡献利润。

## 建议的通用骨架
业务增量目标 → 人群×情境×障碍 → 核心价值主张×可信证据 → 阶段任务×内容×触点 → 购买/使用承接 → 分层测量与增量评估。

并行考虑两条时间线：长期建立记忆和信任；短期捕获需求和转化。主人群/主目标明确不等于不能有次目标与护栏。
