## 一、本次修复背景

用户反馈：之前跑出来的达人，前几个达人的**最低曝光和点赞是错的，导致 CPE 不准**。

根因有三层：
1. **抽屉 DOM 提取 JS 里 `\n` 被 Python 转义成换行** → 抽屉提取整体 `SyntaxError` 崩溃（最低曝光全空）
2. **`get_min_like_coop_note` 的 `likeNum or inf`** → 0 点赞笔记被当 inf 跳过
3. **互动字段只依赖抽屉 DOM**，`notes_detail` API 自带的 `readNum/likeNum/collectNum` 未利用
4. （v2.0.5 追加）**合作笔记 segment 切换不触发新 API 请求** → notes_detail 为空，抽屉提取段被 `continue` 跳过
