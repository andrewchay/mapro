# Campaign 目标设定

## 这个 Skill 做什么

在 Campaign 正式启动前，基于品牌诊断与市场环境，设定清晰、可量化、可执行的 Campaign 目标体系：

- **总目标**：Campaign 要解决的核心商业问题
- **分层目标**：按平台、阶段、人群、内容类型拆解
- **量化指标（KPI）**：可追踪、可复盘的具体数字目标
- **目标优先级**：当资源有限时，明确首要目标与次要目标
- **基准与假设**：目标背后的数据依据与合理假设

## 何时使用

**合适的场景：**
- Campaign 启动前需要明确目标
- 需要向团队/客户统一 KPI 口径
- 从品牌诊断进入策略执行前的目标拆解
- 多平台 Campaign 需要分层设定目标
- 比稿阶段需要呈现目标体系

**不合适的场景：**
- 没有品牌诊断输入时（需要先完成品牌 DNA/诊断）
- 已有明确目标，只需要优化执行
- 测试数据已存在，需要基于数据优化（应使用 ma-campaign-optimizer）

## 工作流

### Step 1 · 输入确认

确认以下信息：

| 信息项 | 说明 |
|--------|------|
| 品牌/产品 | 品牌名称、产品/服务信息 |
| 品牌阶段 | 起步期/成长期/成熟期/焕新期 |
| 核心问题 | 当前要解决的是认知/转化/口碑问题 |
| 目标人群 | TA 画像、核心需求、触媒习惯 |
| 投放平台 | 小红书/抖音/B站/微博/快手等 |
| 总预算 | Campaign 总预算范围 |
| 投放周期 | 起止时间、关键节点 |

### Step 2 · 总目标设定

基于品牌诊断，确定本阶段要解决的核心问题：
- **认知型目标**：建立品类认知、提升品牌知名度
- **转化型目标**：拉动搜索/购买转化、提升 ROI
- **口碑型目标**：改善品牌口碑、建立用户信任
- **验证型目标**：验证内容模型/达人组合/平台策略

### Step 3 · 分层目标拆解

按维度拆解总目标：

| 维度 | 示例 |
|------|------|
| 平台 | 小红书：建立种草心智；抖音：提升搜索转化 |
| 阶段 | 测试期：验证爆文模型；放量期：扩大声量 |
| 人群 | 核心人群：提升认知；潜力人群：拉新触达 |
| 内容 | 场景种草：提升互动；产品测评：促进转化 |

### Step 4 · 量化指标设计

为每个分层目标设定可量化 KPI：

| 指标类型 | 具体指标 | 说明 |
|----------|----------|------|
| 曝光指标 | 曝光量、触达人数、CPM | 衡量声量 |
| 互动指标 | 互动率、CPE、点赞/评论/收藏数 | 衡量内容质量 |
| 搜索指标 | 搜索量、搜索排名变化、搜索转化率 | 衡量种草效果 |
| 转化指标 | ROI、CPC、客单价、购买转化率 | 衡量销售效果 |
| 内容指标 | 爆文率、完播率、笔记合格率 | 衡量内容效率 |

### Step 5 · 目标优先级与约束

明确：
- 首要目标（只能有一个，资源冲突时优先保障）
- 次要目标（最多 2-3 个）
- 目标之间的冲突与取舍
- 不可行目标的调整建议

## 输出格式

建议以结构化 Markdown 输出：

```markdown
# Campaign 目标设定

## 总目标
[一句话描述核心目标]

## 分层目标

### 平台维度
- 小红书：...
- 抖音：...

### 阶段维度
- 测试期：...
- 放量期：...

## 量化指标（KPI）

| 指标 | 目标值 | 衡量方式 | 责任方 |
|------|--------|----------|--------|
| 曝光量 | 1000万 | 平台后台 | 媒介 |
| CPE | < 5元 | 平台后台 | 内容 |
| ROI | > 1:3 | 电商后台 | 增长 |

## 目标优先级
1. 首要目标：...
2. 次要目标：...

## 基准与假设
- 假设1：...
- 数据来源：...
```

## 规则

1. **目标必须具体可量化**：避免"提升品牌知名度"，应改为"小红书曝光量达到 1000 万"
2. **总目标只能有一个核心**：当目标冲突时，必须明确优先级
3. **KPI 必须可追踪**：每个指标都要说明数据来源与统计方式
4. **分层目标必须对齐总目标**：每层目标都要说明如何支撑总目标
5. **给出合理目标区间**：基于市场/竞品/品牌阶段，给出保守/目标/挑战三档
6. **明确目标假设**：说明目标设定的数据依据，避免脱离现实的数字
7. **与品牌诊断保持一致**：目标必须回应品牌诊断中定义的核心问题
