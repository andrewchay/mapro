# 目标受众（TA）画像构建

## 这个 Skill 做什么

基于品牌信息和行业背景，构建完整的 TA 画像，并提炼可用于传播的消费者洞察：
- **核心 TA**：人口统计、心理特征、消费行为、痛点与欲望
- **潜质 TA**：与核心 TA 的差异和激活策略
- **社交语言**：TA 的真实用语和表达习惯
- **Persona 原话**：模拟 TA 的口吻和情绪
- **消费者洞察（Consumer Insight）**：带张力的人性真相，区分 Observation 与 Insight
- **传播切入点（Entry Point）**：基于洞察的传播角度

## 何时使用

**合适的场景：**
- 品牌定位前的受众洞察
- 内容策略制定时的受众校准
- KOL 筛选标准的建立
- 创意概念验证时的受众匹配
- 新市场/新品类拓展时的受众探索

**不合适的场景：**
- 已有详细用户研究报告时
- 纯执行层面的单次内容创作
- B2B 企业的决策链分析（需要不同的分析框架）

## 工作流

### Step 1 · 信息收集

收集以下信息：
| 信息项 | 说明 |
|--------|------|
| 品牌/产品 | 核心功能和卖点 |
| 行业背景 | 品类特征和消费习惯 |
| 现有客群 | 已知的用户特征（如有） |
| 价格带 | 影响目标人群的收入层级 |
| 投放区域 | 国内/海外，影响文化背景 |

### Step 2 · 画像构建

基于信息构建核心 TA 和潜质 TA 的完整画像。

**消费驱动力判定（必做）**：消费只解决两个问题——**满足感**（功能、物质回报：好用、划算、省事）与**存在感**（身份、圈层表达：想被看见、想归属、想晒出来）。必须对品类给出明确判定：

- 存在感主导：内容与选人策略偏向身份认同、圈层黑话、晒单仪式感；KOL 是圈层的"身份符号"而非流量渠道
- 满足感主导：内容偏向教程、对比、功效证据；KOL 是可信的"专业背书"
- 双驱动：区分哪一类内容承接哪一层驱动

同时识别 TA 所属的**圈层部落**（如球鞋圈、露营圈、娃友圈）：部落有自己的语言、仪式和身份层级，进入部落的路径是画像的关键组成部分。

**情境颗粒度（强制）**：persona 与痛点禁止停留在"标签 + 情绪"层（如"新手妈妈的身份焦虑""怕被忽视"），核心情境必须按四要素落到可被内容直接引用的具体程度：
- **事件**：具体发生了什么（"第一次独自带娃过夜"而非"照顾宝宝很累"）
- **解释**：她如何解读这件事（自我评价框架，如"别人都应付得来，是不是我不行"）
- **约束**：是什么让她无法简单解决（时间/精力/决策权/支持缺口）
- **支持**：什么样的支持能改变处境（可被品牌或内容回应的具体形式）

四要素写不齐说明研究仍停在泛化层，回到 Step 1 补信息；产出中禁止用"焦虑""压力大"等情绪词替代情境描述。

### Step 3 · 验证与反证检验

通过 persona_quotes 验证画像是否真实可信。

**反证检验（强制）**：对画像核心结论（痛点、洞察、消费驱动力判定）逐一列出 2-3 个**能推翻它的反例**——不同子人群、不同情境、竞争性解释（该现象是否另有更简单的成因）——并给出判定：
- 站得住 → 在产出中注明"已检反例"及反例内容
- 站不住 → 降级为[待验证假设]，标注验证路径（访谈/搜索/数据补充），禁止以确定语气进入下游

禁止产出"情感连接已经充分""用户一定需要"这类未经反证检验的封闭式结论——此类结论在客户复核中被撤回时，下游全部策略资产随之作废。

在工作流 / 生成到 `user-analysis/` 目录的上下文中：**必须将分析落盘为三份 Markdown 文件保存到 `user-analysis/` 目录**，命名与结构如下（见下方「工作流落盘规范」）。

### 工作流落盘规范（写到 user-analysis/ 目录）

1. `ta-portrait.md` — 目标受众画像，必须包含并明示小标题与措辞：
   - `## 人口统计`：年龄 / 性别 / 收入 / 城市 / 地域 / 学历 / 职业
   - `## 兴趣偏好`：兴趣 / 偏好 / 爱好 / 生活方式 / 消费观
   - `## 痛点需求`：痛点 / 需求 / 场景 / 问题 / 欲望 / 动机（含购买的 battle 与 barrier）
   - `## 消费驱动力`：满足感 vs 存在感的明确判定（存在感主导 / 满足感主导 / 双驱动）+ 判定依据 + TA 所属圈层部落及其语言、仪式、身份层级 + **购买任务一句话**（当＿＿时，我想要＿＿，好让我＿＿，必带情境）
2. `search-habits.md` — 搜索习惯：
   - `## 搜索平台`：小红书 / 抖音 / 百度 / 知乎 等
   - `## 搜索场景`：种草前 / 决策中 / 使用后
   - `## 搜索关键词`：核心词 / 长尾词 / 竞品词列表
3. `consumer-insight.md` — 消费者洞察与传播切入点：
   - `## 消费者洞察`：Observation（现象）与 Insight（动机/冲突），带人性张力
   - `## 传播切入点`：entry point，创意团队可直接发想的传播角度

三份文件合计不少于 300 字；每份小标题必须字字精确（如「兴趣偏好」「搜索习惯」「消费者洞察」「传播切入点」），并在正文自然使用关键词（兴趣、偏好、搜索、关键词、洞察、insight、切入点），确保机器人校验可识别。

在**非工作流**的普通对话中：仍按下方 JSON 输出。

## 规则

1. **pain_points 和 desires 要形成张力**，如"想要专业表现，也在意风格表达""追求效率，但不愿牺牲品质"
2. **social_terms 要用 TA 的真实语言**，不是品牌语言，如"绝了""狠狠爱住"而非"卓越品质"
3. **persona_quotes 要像真实用户说的话**，带情绪和细节，避免"这个产品很好用"这类平淡表达
4. **potential_ta** 必须有明确的 **gap_from_core** 和 **activation_strategy**
5. 如果是海外投放，增加文化背景和当地社交平台习惯
6. consumption_behavior 要具体到平台和行为，如"小红书搜索→收藏→比价→下单"
7. **insight 必须带张力**：不是"消费者喜欢美的"这类常识，要体现人性冲突，如"想要专业表现，也在意风格表达"
8. **observation 是现象，insight 是动机**： observation 描述"看到什么"，insight 解释"为什么这样"
9. **entry_point 必须可传播**：是创意团队能直接发想内容的入口
10. confidence_score 诚实评估，信息不足时降低分数并标注缺失项
11. **consumption_drive 必须给明确判定**，不允许"两者都有"的模糊表述；双驱动也要说明主次与各自承接的内容类型
12. **圈层部落要具体到语言和仪式**：部落内如何称呼彼此、入坑仪式是什么、身份层级怎么划分，写不出来说明画像还没做深
13. **purchase_job 必须带情境且过"跨品类检验"**：把任务句式里的动机拿掉品牌名，若只有本品类产品能"应聘"这份任务，说明写的是产品需求不是购买任务，重写
14. **情境四要素**：核心 persona 与痛点必须落到事件/解释/约束/支持四要素；只有情绪标签没有具体事件的按泛化处理，重写
15. **反证检验**：核心结论必须附 2-3 个反例及"为何仍成立"或降级[待验证假设]的说明；下游引用时继承该标注，不得静默转为已确认事实
16. **功效表述过滤**：引用品牌方材料中的功效说法（如"缓解乳腺炎""助眠舒压""X 小时见效"）时，只能标注为「品牌声称·资质未核验·不用于对外表达」，或转译为中性需求描述（如"希望减少哺乳期身体不适的反复"）；受限品类（普通食品等）的疾病功效表述禁止原样写入使用场景、购买动机等产出字段——用户研究描述的是需求语境，不是产品承诺
