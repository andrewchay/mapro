# 达人内容审核

## 这个 Skill 做什么

从三个核心维度系统审核 KOL 提交的内容，输出结构化评分与修改建议：
- **合规性审核**：敏感词检测、平台规范符合度、广告法合规性
- **品牌契合度审核**：品牌调性匹配、核心信息传递准确性、视觉风格一致性
- **内容质量审核**：创意性评估、互动潜力预判、完成度检查

## 何时使用

**合适的场景：**
- KOL 提交内容后的正式审核流程
- 品牌方对达人脚本/视频/图文的内容质检
- 投放前的合规性把关
- 批量达人内容的快速筛查
- 内容修改后的二次审核

**不合适的场景：**
- 内容创意方向的早期讨论（用 ma-creative-concept）
- 纯品牌视觉设计审核（需设计团队介入）
- 没有具体审核内容时

## 工作流

### Step 1 · 输入确认

确认以下信息是否充足：
| 信息项 | 说明 |
|--------|------|
| 品牌 | 品牌名称及品牌 DNA |
| 产品 | 具体产品/服务信息 |
| 平台 | 内容发布平台（小红书/抖音/B站等） |
| 内容类型 | 视频/图文/直播脚本/口播 |
| 内容描述/脚本 | 待审核的具体内容或脚本全文 |

### Step 2 · 三维度审核

逐维度进行审核，记录发现的问题：
- **合规性**：检查敏感词、平台规范、广告法（极限词、虚假宣传、医疗/食品等特殊品类规范）
- **品牌契合度**：检查品牌调性是否匹配、核心卖点是否准确传递、视觉风格是否一致
- **内容质量**：评估创意性、互动潜力（钩子设计/评论区引导）、完成度（结构完整性/信息密度）

### Step 3 · 评分与建议

每个维度给出 0-100 分评分，计算综合评分，输出具体修改建议（含修改后示例）。

## 输出格式

必须以 JSON 格式返回：

```json
{
  "audit_summary": "审核结论概述",
  "compliance_check": {
    "score": 85,
    "issues": ["发现的问题1", "发现的问题2"],
    "suggestions": ["修改建议1", "修改建议2"]
  },
  "brand_alignment": {
    "score": 90,
    "matches": ["契合点1", "契合点2"],
    "mismatches": ["不匹配点1", "不匹配点2"]
  },
  "quality_assessment": {
    "score": 88,
    "strengths": ["优势1", "优势2"],
    "weaknesses": ["不足1", "不足2"]
  },
  "revision_suggestions": [
    {
      "location": "具体段落/画面/时间点",
      "issue": "问题描述",
      "suggestion": "修改建议",
      "example": "修改后的示例文本"
    }
  ],
  "overall_score": 88,
  "final_verdict": "通过 | 需修改 | 不通过"
}
```

## 规则

1. **合规性一票否决**：如有严重违规（虚假宣传、敏感内容、违反广告法极限词），直接判定为"不通过"，overall_score 不超过 59
2. **品牌契合度关注核心信息传递**：重点检查产品卖点是否准确、品牌调性是否被达人个人风格冲淡或扭曲
3. **质量评估要具体**：指出具体段落、画面或时间戳的问题，不笼统评价"创意一般"
4. **修改建议必须可操作**：每条建议都要给出修改后的示例，让达人知道"改成什么样"
5. **平台规范差异化**：不同平台（小红书/抖音/B站）的审核标准不同，需按平台规则检查（如小红书的"种草感"、抖音的"前3秒钩子"）
6. **评分标准统一**：90-100 优秀可直接发布，70-89 需修改后发布，50-69 需大幅修改，0-49 不通过需重做
7. **保持客观中立**：审核意见基于事实和规则，不因达人粉丝量大小而放宽标准
