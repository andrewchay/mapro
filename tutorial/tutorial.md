## 在开始之前

欢迎使用 **MAPro** —— 专为社交营销团队打造的 AI Agent 平台。

MAPro 将广告公司的核心工作流拆解为 **5 个智能角色**：

| 角色 | 职责 | 对应能力 |
|------|------|----------|
| **策略总监** | 品牌定位、创意方案、传播策略 | 策略生成、品牌 DNA 分析 |
| **媒介总监** | 达人筛选、组合投放、投流助推 | KOL 匹配、金字塔投放、效果预测 |
| **商务助理** | 达人建联、合作商务、CRM 管理 | 智能建联、CRM 管理、合作跟进 |
| **内容总监** | 品牌内容、达人审阅、内容审核 | 脚本创作、内容审核、历史审阅 |
| **达人端** | 入驻信息、内容指导、效果看板 | 个人资料、创作指导、数据看板 |

MAPro 的核心价值是 **"让每一分投放都有复利"** —— 通过 AI 将策略、达人、内容、数据串联起来，实现可积累、可复用的营销资产。

## 快速开始

### 下载和安装

MAPro 基于开源项目构建，支持 macOS、Windows 和 Linux。

**开源版本下载地址**：https://github.com/andrewchay/mapro/releases

Windows 用户推荐安装到 `C 盘`，这样会对营销工具脚本的执行更加友好。

### 首次启动

完成安装后，第一次启动会看到欢迎界面：

- **查看营销工作流教程**：了解 MAPro 的完整营销 Agent 工作流
- **从其他设备迁移**：导入已有的营销项目配置
- **导入团队配置**：从同事处导入工作区配置

Windows 用户会额外看到环境检测步骤，用于确认 Git Bash 或 WSL 可用（部分营销工具脚本需要）。

## AI 供应商渠道和模型配置

AI 供应商渠道是 MAPro 调用大模型的通道。常见的供应商包括 DeepSeek、豆包、千问、SiliconFlow 等。

MAPro 支持全部的供应商渠道和主流格式（OpenAI 兼容格式、Anthropic 格式以及 Gemini 格式）。

### 配置步骤

1. 点击左下角 **设置** → **渠道** → 右上角 **添加渠道**
2. 填写 **渠道名称**（任意填写，用于区分）
3. **供应商类型** 选择你的供应商类型
4. **BaseUrl** 填写供应商提供的地址（无需添加 `/v1` 后缀，MAPro 自动处理）
5. **API KEY** 粘贴你的凭证
6. 点击 **测试链接** 验证配置是否正确

### 模型配置

配置好渠道后，继续配置模型列表：

- 点击 **从供应商获取** 拉取所有可用模型
- 勾选你需要的模型（推荐只配置必要的模型，避免列表过长）
- 滚动到顶部点击 **创建渠道** 保存

**Agent 模式要求**：如果该渠道将用于 Agent 模式，必须选择支持 `Anthropic` 格式的供应商。

## 记忆工具 / 联网工具配置

MAPro 支持通过 MemOS 和 Tavily API 来分别实现记忆能力和联网搜索能力。这两项能力会极大增强营销场景的使用体验。

### MemOS API 配置（记忆）

MemOS 提供每月免费用户的 5 万次记忆存储和 2 万次记忆调用。

1. 访问 MemOS API 官网并注册账户
2. 在控制台生成 API KEY
3. 将 API KEY 粘贴到 MAPro 记忆部分的输入框，点击测试链接

**记忆功能的作用**：
- 自动记录你的品牌偏好、达人合作历史、内容风格偏好
- 跨对话保持一致的品牌认知
- 主动记住你的营销策略和决策逻辑

### Tavily 联网搜索配置

Tavily 每月提供 1000 次免费联网搜索。

1. 点击设置 → 工具 → 打开联网搜索开关
2. 访问 Tavily 官网注册并获取 API KEY
3. 粘贴到 MAPro 并测试链接

**联网搜索的作用**：
- 获取最新的行业趋势、竞品动态
- 查询达人最新数据和热点话题
- 验证营销策略的时效性

## MAPro 营销工作流

### 工作区设计

MAPro 采用 **工作区** 来组织不同类型的营销项目：

- **品牌策略工作区**：品牌定位、创意方案、传播策略
- **达人运营工作区**：达人筛选、建联、CRM、效果追踪
- **内容生产工作区**：脚本创作、内容审核、发布管理
- **投放优化工作区**：A/B 测试、组合优化、ROI 分析

每个工作区可以配置不同的 **Skills** 和 **MCP**，实现专业化的营销能力组合。

### 5 大角色工作流

#### 1. 策略总监 —— 从品牌定位到传播方案

**典型工作流**：

1. 输入品牌信息和目标受众
2. MAPro 生成品牌 DNA 分析（定位、调性、差异化）
3. 基于品牌 DNA 生成创意概念方案
4. 将创意概念转化为可执行的传播策略
5. 输出完整的营销方案文档

**使用的 Skills**：`ma-brand-dna`、`ma-brand-house`、`ma-creative-concept`、`ma-marketing`

#### 2. 媒介总监 —— 从达人筛选到投放优化

**典型工作流**：

1. 输入 campaign 目标和预算
2. MAPro 从 KOL 数据库筛选匹配达人
3. 生成达人金字塔组合方案（头部/腰部/尾部配比）
4. 预测投放效果和 ROI
5. 执行投放并持续优化组合

**使用的 Skills**：`ma-kol-search`、`ma-kol-pyramid`、`ma-match-ai`、`ma-paid-media`

#### 3. 商务助理 —— 从建联到 CRM

**典型工作流**：

1. 识别目标达人列表
2. 生成个性化建联话术（基于达人画像）
3. 发送合作邀约并跟进
4. 录入 CRM 并标记合作状态
5. 定期复盘达人合作价值

**使用的 Skills**：`ma-connect-bot`、`ma-kol-crm`

#### 4. 内容总监 —— 从脚本到审核

**典型工作流**：

1. 接收品牌 Brief 和达人信息
2. 生成平台-specific 的脚本方案
3. 审核达人提交的内容（合规性、品牌调性）
4. 提供修改建议并追踪版本
5. 归档内容资产供复用

**使用的 Skills**：`ma-script-studio`、`ma-content-audit`、`ma-kol-history-review`

#### 5. 达人端 —— 自助服务门户

**达人可以**：

1. 查看和更新个人资料（专长、风格、受众）
2. 获取品牌 Brief 的内容创作指导
3. 查看个人合作效果数据看板
4. 了解平台分层等级和升级路径
5. 查看参与的合作活动列表

**使用的 Skills**：`ma-kol-portal`

## Chat 模式

Chat 模式适合快速问答、策略讨论、创意头脑风暴等场景。

### Chat 模式的功能

1. **支持文件解析**：PDF、Word、Markdown、图片等（注意：复杂格式建议用 Agent 模式）
2. **支持粘贴图片和文本**：直接复制粘贴到输入框
3. **支持切换模型和渠道**：根据场景选择不同模型
4. **支持思考模式**：需要模型供应商支持
5. **语音输入**：浏览器自带语音识别
6. **联网和记忆**：打开相关开关即可使用
7. **上下文调整**：缩短上下文节省 tokens
8. **清除上下文**：Ctrl+K / Command+K 快捷键
9. **置顶对话**：将常用话题置顶，方便快速访问

### Chat 模式的营销场景

- **策略讨论**："帮我分析这个品牌的定位是否清晰"
- **创意头脑风暴**："给这个美妆品牌想 10 个短视频创意"
- **达人评估**："这个达人的粉丝画像和我们的目标受众匹配吗？"
- **竞品分析**："分析竞品最近 3 个月的投放策略"
- **快速查询**："小红书最近的美妆热点话题是什么？"

**注意**：Chat 模式无法修改文件、无法执行复杂的多步骤工作流。涉及文件处理、深度研究、批量操作请使用 Agent 模式。

## Agent 模式

Agent 模式是 MAPro 的核心能力，适合复杂的营销项目执行。

### 前提条件

- 至少配置一个支持 `Anthropic` 协议的渠道
- Windows 用户需要 Git Bash 或 WSL 环境（用于执行营销工具脚本）

### Agent 模式的基本概念

Agent 模式通过调动 **Skills** 和 **MCP** 来完成复杂任务：

- **Skills**：营销工作流的结构化知识（如品牌定位流程、达人筛选标准）
- **MCP**：外部服务的包装（如飞书文档、钉钉通知、KOL 数据 API）

### 营销 Agent 的典型任务

1. **生成完整营销方案**：从品牌分析 → 策略制定 → 达人组合 → 内容规划 → 投放计划
2. **批量达人筛选**：根据 campaign 需求，从数据库筛选、评估、排序达人
3. **内容批量审核**：审核多个达人的内容提交，输出审核报告
4. **投放效果分析**：读取效果数据，生成 ROI 分析和优化建议
5. **自动化报告生成**：将分析结果输出为 PPT/Word 报告

### 工作区与 Skills 配置

每个营销项目建议创建独立工作区，配置对应的 Skills：

- **品牌策略工作区**：启用 `ma-brand-dna`、`ma-creative-concept`
- **达人运营工作区**：启用 `ma-kol-search`、`ma-match-ai`、`ma-kol-crm`
- **内容生产工作区**：启用 `ma-script-studio`、`ma-content-audit`
- **投放优化工作区**：启用 `ma-campaign-optimizer`、`ma-campaign-tester`

### SubAgent 协作

复杂任务中，主 Agent 可以将子任务委派给不同 SubAgent：

- `explorer`：探索调研（如竞品分析、趋势研究）
- `researcher`：深度研究（如受众画像、平台算法）
- `code-reviewer`：审核营销代码/脚本

在右侧 Team 侧边栏可以查看 Agent 间的协作过程。

## 飞书 / 钉钉 / 微信集成

MAPro 支持通过飞书、钉钉、微信远程访问 Agent。

### 飞书配置

1. 点击设置 → 飞书选项
2. 按照文字教程完成配置（约 3-5 分钟）
3. 配置完成后，可以通过飞书群聊或私聊指派任务给 MAPro Agent

### 钉钉配置

1. 点击设置 → 钉钉选项
2. 按照文字教程完成配置
3. 支持钉钉群聊和私聊交互

### 微信配置

1. 点击设置 → 微信选项
2. 按照文字教程完成配置
3. 支持微信消息交互

### 远程使用的营销场景

- **外出时指派任务**："帮我分析一下这个 campaign 的达人组合是否合理"
- **接收报告**：Agent 完成分析后，将报告发送到你的飞书/钉钉
- **紧急调整**："暂停当前投放，重新筛选一批达人"
- **团队协作**：团队成员通过群聊共享 Agent 任务和结果

## 最佳实践

### 1. 从简单开始

不要试图一次性配置完整的工作流。建议：

1. 先配置 AI 供应商和基础工具（记忆、联网）
2. 从一个具体的 campaign 开始，创建对应工作区
3. 逐步添加 Skills 和 MCP，优化工作流
4. 积累数据和经验后，再扩展到更多场景

### 2. 善用工作区隔离

不同 campaign、不同品牌、不同团队建议用独立工作区：

- 避免 Skills 和 MCP 冲突
- 保持上下文清晰，减少 tokens 消耗
- 便于团队协作和权限管理

### 3. 持续优化 Skills

Skills 不是一成不变的，建议：

- 每次 campaign 后复盘，优化 Skills 内容
- 记录成功的策略和失败的教训
- 与团队共享高质量的 Skills

### 4. 数据驱动决策

MAPro 提供了丰富的数据能力：

- 定期查看 KOL CRM 的分层变化
- 分析 campaign 效果数据，优化投放策略
- 追踪内容审核通过率，优化 Brief 质量

## 常见问题

**Q: MAPro 是什么？**
A: MAPro 是一个本地优先的 AI 桌面应用，把多模型 Chat、通用 Agent、工作区、Skills、MCP、远程机器人和记忆能力放在同一个开源客户端里，支持 KOL 投放项目管理（Campaign）等营销场景工作流。

**Q: 我需要编程基础吗？**
A: 不需要。MAPro 的所有配置和操作都通过自然语言对话完成。Windows 用户只需按引导安装 Git Bash 即可。

**Q: 达人端是独立的应用吗？**
A: 目前达人端通过 Chat Tool (`ma-kol-portal`) 提供服务，达人可以通过对话方式查看资料、获取指导、查看数据。未来可能推出独立的达人端界面。

**Q: 我的营销数据安全吗？**
A: MAPro 的所有数据存储在本地 SQLite 数据库，不会上传到云端。AI 供应商仅接收必要的对话内容。

**Q: 可以多人协作吗？**
A: 可以通过飞书/钉钉/微信集成实现远程协作，也可以通过导出/导入工作区配置来共享团队设置。
