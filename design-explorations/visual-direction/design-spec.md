# MAPro 视觉方向提案 · Design Spec

## 1. 产品是什么

MAPro 是一个集成通用 AI Agent 的下一代人工智能桌面应用，采用 Electron 架构，核心模式包含：
- **Chat 模式**：标准多模型对话，支持附件、代码高亮、并排对比。
- **Agent 模式**：基于 Claude Agent SDK 的自主任务执行，含工作区、MCP Server、权限/AskUser/Plan 审批交互。
- **Campaign 项目管理**：面向营销投放的 13 步标准工作流，覆盖 KOL 候选池、Brief、内容审核、内容追踪、AB Test、复盘。

产品定位是「专业营销人员的 AI 指挥中心」，不是消费级聊天机器人，也不是纯开发者工具。用户是每天有真实工作流的营销从业者、AI 高级用户和内容团队。

## 2. 目标受众与使用场景

- **主要用户**：品牌营销经理、内容运营、媒介投放、KOL 运营、AI 工作流搭建者。
- **使用场景**：长时间挂在桌面的生产力工具；需要同时处理多个对话/Agent 会话/Campaign 项目；重视信息密度和快速切换；对界面响应速度和键盘效率敏感。
- **设备环境**： primarily 桌面端（macOS / Windows），窗口宽度 1280–1920px，多标签页同时打开。
- **用户期待**：看起来「专业、可靠、聪明」，而不是「玩具感」或「又一个 AI 聊天网页」。

## 3. 核心信息与内容要点

三个必须呈现的屏幕：

### 屏幕 A · Agent 会话主界面
- 顶部：会话标题（可编辑）、渠道/模型选择、工作区选择、设置入口。
- 中部：消息流（用户消息 + Agent 消息 + 工具调用卡片 + 权限/AskUser/Plan 横幅）。
- 底部：富文本输入框（Tiptap）、附件预览、发送/停止按钮、权限模式选择器。
- 右侧（可选）：文件浏览器 / Diff 面板。

### 屏幕 B · Campaign 详情页
- 头部：返回、Campaign 名称、平台标签、状态标签。
- 信息卡片区：总预算、投放周期、目标城市、目标 KOL 数等。
- 三阶段进度：策略制定 → 达人筛选 → 投放执行，每阶段含状态与入口。
- 标签页：候选池 / Brief / 内容审核 / 内容追踪 / AB Test / 复盘。

### 屏幕 C · 外观设置页
- 主题模式切换：浅色 / 深色 / 跟随系统 / 特殊风格。
- 特殊风格网格：6 个主题预览卡片。
- 应用图标选择器：多种图标变体。
- 界面缩放提示。

## 4. 情感基调与气质关键词

- **Calm Authority（冷静的权威感）**：不要活泼，不要可爱，不要过度科技感。
- **Focused Productivity（专注的生产力）**：减少视觉噪音，帮助用户进入心流。
- **Intelligent but Not Overbearing（聪明但不压迫）**：AI 的存在感通过 subtle 的 accent、光晕、动效表达，而不是大面积机器人头像或闪烁霓虹。
- **Marketing Command Center（营销指挥中心）**：信息密度高但有序，像专业工具而非社交媒体 App。

气质关键词：**精确、沉稳、通透、有节奏、现代主义、克制的温度**。

## 5. 输出格式与尺寸

- 每个方向输出 **1 个独立的单文件 HTML**（双击可用浏览器打开）。
- 每个 HTML 展示上述 **3 个屏幕的静态 mockup**，按垂直排列或标签切换方式呈现。
- 画布尺寸：**1440 × 900**（桌面窗口基准），每个屏幕按此比例绘制，HTML 自身实现响应式缩放。
- 输出路径：`design-explorations/visual-direction/[direction-name].html`。
- 必须内联所有资源（CSS、图标、logo），不允许相对路径图片。

## 6. 已知约束

- 必须保留现有布局骨架：左侧边栏 + 中间主内容区 + 右侧可折叠面板。
- 必须支持深色/浅色两种基础模式（mockup 至少展示 dark 主题，如方向本身偏 light 可展示 light）。
- 必须使用 MAPro 现有 logo（已提供 SVG 内联）。
- 保持中文界面文案。
- 不引入需要外部网络请求的字体或图片。
- 不使用 emoji 作图标，使用 Lucide-style 线条图标（可用 inline SVG 或 CSS 模拟）。

## 7. 图片素材策略

本提案为「UI 界面 mockup」，内容即界面本身，不需要外部摄影图或产品图。
- **Logo**：使用项目内 `apps/electron/resources/icon.svg`，以 base64/inline SVG 方式嵌入。
- **头像/缩略图**：使用抽象几何占位或首字母头像，不依赖真实人物照片。
- **图标**：使用简洁的线条图标，统一 16px / 18px / 20px 规格。
- **预览图**：特殊风格卡片可用 CSS 渐变/几何图形示意，不必须真实截图。

## 8. 视觉母题假设

MAPro 的核心隐喻是 **「Agent 的思考之流」** —— 信息不是静止的卡片，而是像水流一样在界面中传递、汇聚、分流。视觉母题可以从这个隐喻推导：
- **流动的边界**：选中态、焦点态、分隔线使用 subtle 的渐变或光晕，暗示状态在变化。
- **层叠的深度**：通过 elevation、背景透明度变化表达工作区/会话/任务的层级。
- **精确的标点**：小圆点、短线、badge 作为状态标点，像乐谱上的音符一样标记节奏。
- **品牌签名**：一个贯穿三屏的视觉元素（如统一的 accent 色光晕、特定的圆角节奏、特定的消息气泡形态），让人一眼认出是 MAPro。

每个方向应围绕上述母题给出不同的诠释，而不是单纯换色。
